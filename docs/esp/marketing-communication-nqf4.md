# ESP blueprint — Marketing Communication (NQF Level 4)

Source analysed: Macmillan SA public preview of *FET First Marketing Communication NQF Level 4 Student's Book* (B. Brown, 2011, Troupant/Macmillan, ISBN 978-1-920334-60-4).
Preview = 37 pages: cover, contents, all of Topic 1, start of Topic 2.

Copyright note: the book is "All rights reserved". This file keeps only the syllabus structure and our own ESP design. Do not copy the book's text, case studies or activities into the LMS. Write original texts and tasks on the same topics.

## 2. ESP course map (proposed)

Each ESP unit pairs one content topic with one language focus and one real marketing genre.

| ESP unit | From | Language focus | Skill output (genre) |
|---|---|---|---|
| 1 Who are our stakeholders? | T1 | classifying language (*consist of, fall into, be categorised as*); internal vs external; contrast linkers | stakeholder map + 150-word description |
| 2 Managing relationships | T1 M2–M3 | cause–effect (*lead to, result in, affect*); modals for obligation/expectation | short stakeholder-relations memo |
| 3 Culture and the customer | T2 M4–M6 | defining (*X is a … that/which …*); hedging (*tend to, may, often*) | consumer profile of a cultural/sub-cultural segment |
| 4 Avoiding prejudice and stereotypes | T2 M7–M8, T3 | evaluative and inclusive language; softening criticism | critique of an ad + rewritten inclusive slogan |
| 5 What is marketing? | T4 | marketing core terms (4Ps, target market, positioning); persuasive structures | 2-minute persuasive pitch on "marketing culture" |
| 6 Professional work ethics | T5 | meeting/briefing language; requests, deadlines, apologies, follow-ups | briefing notes + follow-up email |
| 7 Writing a marketing proposal | T6 | proposal structure; future/conditional; formal register; legal/ethical vocabulary | 1-page campaign proposal |
| 8 Presenting the proposal | T7 | signposting; describing visuals/data; handling Q&A | 5-minute slide presentation |
| 9 Business writing formats | T8 | register; memo/letter/report conventions; conciseness; proofreading | letter + memo + short report |
| 10 Digital marketing communication | T9 | complaint-reply email; search terms; press-release headline/lead style; pamphlet copy | complaint reply + press release + pamphlet |

## 3. Core vocabulary seed (frequency from the preview)

stakeholder, internal / external stakeholder, shareholder, owner, employee, supplier, customer, community, government, interest, expectation, relationship, influence, impact, benefit, function, market, product, organisation, culture, subculture, attitude, filter, prejudice, stereotyping, ethnicity, advertising, sales promotion.

Extend per unit with: target market, segmentation, positioning, brand, marketing mix (product, price, place, promotion), campaign, brief, deadline, proposal, budget, objective, press release, pamphlet, query, complaint, read receipt, database.

## 4. Assessment pattern

- Per unit: vocabulary check (matching/gap fill), reading comprehension on an original case text, one productive genre task with a rubric.
- Mid-course: stakeholder + culture case analysis (Units 1–4).
- Final: proposal pack = written proposal (U7) + presentation (U8) + launch press release (U10).
